# YouTube Music SEO Tool 🚀

Công cụ All-in-one thiết kế riêng cho các Creator làm nội dung âm nhạc trên YouTube. Giúp bạn tự động tính toán Timestamps (lên đến hàng trăm bài hát), và sử dụng **Google Gemini AI** để tạo ra bộ Mô tả, Hashtag và Tag siêu chuẩn SEO.

## 🌟 Tính năng
- **Giao diện:** Dark Mode chuẩn ứng dụng chuyên nghiệp, reponsive toàn diện.
- **Auto Timestamp:** Tự động bắt thời gian và cộng dồn liên tục. Chỉ cần dán `Tên bài - 04:30`.
- **Tích hợp AI (Gemini):** Tự sinh Mô tả hấp dẫn, không trùng lặp sau mỗi lần nhấn nút.
- **Tự tạo Hashtag & Tag:** Tối ưu hóa chuẩn SEO thuật toán YouTube.
- **Copy & Tải xuống:** Tích hợp nút Copy 1 click, tải kết quả về định dạng `.TXT` và `.DOCX`.
- **Hiệu năng:** Xử lý nhẹ nhàng danh sách dài trên 500+ bài hát mà không bị lag.

## ⚙️ Cài đặt & Sử dụng
1. Tải toàn bộ source code này về chung một thư mục.
2. Mở file `index.html` bằng bất kỳ trình duyệt nào (Chrome, Edge, Safari...). Không cần cài đặt server (chạy trực tiếp dưới dạng `file://`).
3. Truy cập [Google AI Studio](https://aistudio.google.com/) và tạo một API Key (hoàn toàn miễn phí).
4. Dán API Key vào ô cấu hình trên đầu trang web.
5. Copy danh sách bài hát của bạn vào, bấm nút **Tạo Timestamp & SEO (AI)** và tận hưởng kết quả.

> **Lưu ý bảo mật:** API Key của bạn chỉ được lưu nội bộ trên máy tính của bạn (Local Storage của trình duyệt), đảm bảo an toàn tuyệt đối, không bị lộ ra bên ngoài.

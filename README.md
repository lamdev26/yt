# YouTube Music SEO Tool 🚀

Công cụ All-in-one thiết kế riêng cho các Creator làm nội dung âm nhạc trên YouTube. Giúp bạn tự động tính toán Timestamps (lên đến hàng trăm bài hát), và sử dụng **Google Gemini AI** để tạo ra bộ Mô tả, Hashtag và Tag siêu chuẩn SEO.

## 🌟 Tính năng
- **Giao diện 2 Tab chuyên nghiệp:** Chuyển đổi mượt mà giữa **YouTube SEO Tool** và **Suno AI Studio**.
- **Top 3 Tiêu đề SEO Hot:** Tự động tạo 3 phương án tiêu đề tối ưu theo 3 phong cách (Xu Hướng & Trending, Kích thích tò mò High CTR, Chuẩn tìm kiếm YouTube Search) kèm nút **Copy 1-click** riêng cho từng tiêu đề và bộ đếm ký tự chuẩn YouTube.
- **Suno AI Studio (Tạo Lời & Prompt):**
  - Gợi ý 3 thể loại chuẩn kỹ thuật Suno:
    1. `Rap Pop x Jersey Club x Afrobeat` (128 BPM, Jersey bounce, duet nam-nữ ngọt ngào hoặc melodic rap).
    2. `Vietnamese Vinahouse x Big Room EDM` (140 BPM, peak-time festival, vocal nam ấm khàn, 3 drops bass cuộn bùng nổ, hook đắt giá).
    3. `Emotional Pop Ballad x Cinematic Orchestral` (82 BPM, piano da diết, strings cao trào, day dứt, chân thành).
  - **Kiểm soát độ dài Prompt Style:** Bắt buộc từ **800 đến 920 ký tự** (hiển thị bộ đếm Live trực quan).
  - **Lời bài hát sâu sắc:** Câu từ giàu hình ảnh, triết lý cảm xúc, không hời hợt, chuẩn định dạng thẻ `[Verse]`, `[Chorus]`, `[Drop]`, `[Bridge]`.
  - Hỗ trợ nút Copy riêng cho Prompt Style, Lời Nhạc và xuất file `.TXT`.
- **Auto Timestamp:** Tự động bắt thời gian và cộng dồn liên tục. Chỉ cần dán `Tên bài - 04:30`.
- **Tích hợp AI (Gemini):** Tự sinh Mô tả biến tấu theo bài hát, Hashtags và Tags YouTube.
- **Copy & Tải xuống:** Tích hợp nút Copy 1-click, tải kết quả về định dạng `.TXT` và `.DOCX`.

## ⚙️ Cài đặt & Sử dụng
1. Tải toàn bộ source code này về chung một thư mục.
2. Mở file `index.html` bằng bất kỳ trình duyệt nào (Chrome, Edge, Safari...). Không cần cài đặt server (chạy trực tiếp dưới dạng `file://`).
3. Truy cập [Google AI Studio](https://aistudio.google.com/) và tạo một API Key (hoàn toàn miễn phí).
4. Dán API Key vào ô cấu hình trên đầu trang web.
5. Copy danh sách bài hát của bạn vào, bấm nút **Tạo Timestamp & SEO (AI)** và tận hưởng kết quả.

> **Lưu ý bảo mật:** API Key của bạn chỉ được lưu nội bộ trên máy tính của bạn (Local Storage của trình duyệt), đảm bảo an toàn tuyệt đối, không bị lộ ra bên ngoài.
